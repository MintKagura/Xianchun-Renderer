衔春渲染器是方便 Operit 按次长文用户们使用的对话美化包。

---

## 🌸 功能特点

- **文本分流渲染**：支持 `<xc>` 自动分流、`<xc_card>` 精致卡片与 `<xc_html>` 长卷网页。
- **自定义色板预设**：内置七色调配系统，预置专属配色，支持自由微调与保存新预设。
- **提示词自由定制**：支持提示词原位修改、系统提示词自动注入（置顶 / 追加）与一键复制。
- **双语与语音兼容**：支持 `<fold>` 译文折叠对齐与单句 `▷` TTS 语音旁路播放（带文本正则清洗）。
